First launch on macOS

The app isn't signed with an Apple Developer certificate yet, so Gatekeeper blocks it the first time. After dragging Auto Subtitles into Applications, either right-click the app icon and choose Open (then Open again in the dialog), or run this once in Terminal: 

xattr -cr "/Applications/Auto Subtitles.app"

You only need to do this once per install.

First launch on Windows

The installer isn't code-signed yet, so Windows SmartScreen may show “Windows protected your PC”. Click More info → Run anyway to continue. This goes away once the build is signed.

What it does

Auto Subtitles runs whisper.cpp locally to transcribe speech, lets you edit and style the captions (per-word and per-range font, colour, size and outline), then uses a bundled ffmpeg with libass to render them into the video. Nothing leaves your computer.
